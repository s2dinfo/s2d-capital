# Character portraits

Drop a **stylised** character image here and it appears automatically in that figure's
encounter. Until a file exists, a placeholder (monogram + silhouette) shows — nothing breaks.

Expected files (portrait orientation, ~3:4, e.g. 600×800 PNG):
- `jensen.png`        → Jensen Huang (Nvidia)
- `cc-wei.png`         → C.C. Wei (TSMC)
- `fouquet.png`       → Christophe Fouquet (ASML)

## Art direction
- **Stylised / illustrated / game-character — NOT photoreal, NOT real photographs.**
  Recognisable by signature traits (e.g. Jensen: black leather jacket, glasses, silver hair).
- Keep ONE consistent illustration style across all figures so the world feels cohesive.
- Dark, on-brand (gold / navy) framing reads best in the gold-rimmed portrait frame.

## Why stylised (not photoreal)
A realistic likeness of a real, living person — speaking dialogue, on a commercial site —
raises right-of-publicity / deepfake concerns. Stylised editorial/game art is both safer and
more on-brand. The "dramatized from public statements" disclaimer stays in every encounter.
